## What went wrong, and what changed

1. **bootstrap refused an existing checkout** for lack of upstream's 100 GB, a minimum for a new checkout; the whole release used 6 GB. The run went on with the same steps by hand. Now an existing checkout needs `update_minimum`, 25 GB, from `build/requirements.json` ([6132a3d](https://github.com/robyroro/project-ghost/commit/6132a3d)).
2. **Unfinished work on `main`.** `bump` commits on top of the local `main`, and the tag must be on `origin`'s `main`: nine unpushed commits of 4C, without their measurements and mutation checks, would have shipped. They moved to a branch first. The runbook now says to check `main` before `bump`.
3. **Triage:** this time Extended Stable's post did list its fixes, by CVE and severity only; the components are in the Stable post. The runbook says so now.
4. **Pausing a release build** had no documented procedure; [release.md](../../build/release.md#pausing-a-build) has one now.

## What differed from a real release

- The test signing identity, and a draft: the name's trademark gate is open.
- No rollout: the update server isn't deployed (sub-project C).
